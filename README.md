# 商品价格图谱 · PriceAtlas

按地区、商品和计价口径查询价格的 Web 应用。多源报价按权威性权重融合，同时给出零售价、批发价与零售溢价，并标注每个价格的来源、权重和置信度。

- **品类** 8 领域 / 51 品类 / 226 子类 / 678 个代表商品
- **地区** 287 座城市（中国 203 座，覆盖 34 个省级行政区；海外 84 座，52 个国家）
- **数据源** 48 个，A~F 六级权威性权重，批发 25 个 / 零售 23 个
- **行情** 农业农村部全国农产品批发市场价格日报，每日更新，含下月预测

## 功能

| 模块 | 说明 |
|---|---|
| 分类树 | 领域 → 品类 → 子类 → 商品，四级下钻；带绿点的品种有官方实价 |
| 中国地图 | 省级区块按均价着色，城市散点按价格偏离着色，默认显示城市名称 |
| 全球视图 | 海外 84 城排行，与中国中位对比 |
| 价格详情 | 零售/批发双列、溢价、P25–P75 区间、参与源数、置信度、逐源溯源 |
| 城市榜 / 省级榜 | 最贵与最便宜各 12 城；34 个省级行政区均价排名 |
| 对比栏 | 最多 5 城并排，显示相对全国中位的偏离 |
| 权重面板 | 六级权重可实时调整，立即看到价格与置信度的变化 |
| 走势与预测 | 近 12 个月双口径序列；有官方实价的品种给出下月预测与 80% 区间 |

## 数据来源与口径

### 官方行情

农业农村部「全国农产品批发市场价格日报」，接口 `POST https://pfsc.agri.cn/api/FarmDaily/list`，公开、无需鉴权。

| 项 | 说明 |
|---|---|
| 覆盖品种 | 8 个：白条猪、黄牛肉、羊肉、白条鸡、鸡蛋、鲫鱼、鲤鱼、带鱼 |
| 口径 | 全国农产品批发市场批发价，单位 元/公斤 |
| 历史深度 | 近 120 天 |
| 更新方式 | 启动时后台刷新，失败则回退本地缓存 |
| 价格锚定 | 这些品种的当前月价格以最新官方价为准 |

全国口径之外的**城市维度数值**，是按城市物价水平、品类价格弹性和季节性推算的比价参考值，用于横向比较，不等同于各地实际成交价。农产品以外的品类（金属、建材、能源、医药、消费品等）没有同等频率的公开日更源，同理。

### 两种计价口径

| 口径 | 含义 | 典型来源 |
|---|---|---|
| 零售价 | 终端挂牌价 | 发改委价格监测、统计局 CPI 采价、京东/天猫自营、连锁药店、Amazon |
| 批发价 | 出厂 / 批发市场 / 交易所大额成交价 | 农业农村部批发市场、上期所与大商所、LME、上海金交所、我的钢铁、SMM、医保集采中选价、1688 |
| 零售溢价 | `(零售 − 批发) / 批发` | 由上述两者推导 |

每个数据源只进入自己所属口径的池子，不跨口径混算。金属矿产类没有公开零售监测源，只提供批发口径，界面显示为「—」而不是补一个估算值。

## 融合算法

1. **口径对齐**：城市、商品、规格、月份、计价口径全部一致才允许融合；跨币种先折算为人民币。
2. **权重**：`层级基准权重 × (0.55 + 0.45 × 时效衰减)`，时效半衰期 240 天。
3. **离群剔除**：以加权中位数为中心，偏离超过 `max(3.5 × 1.4826 × MAD, 5% × 中位数)` 的源剔除。5% 下限用于避免小样本下 MAD 过窄而误杀正常的层级价差。
4. **主值**：剔除后取**加权平均**。不用中位数，是因为层级之间存在系统性价差，中位数会随「哪一层落在中间」整档跳变。
5. **区间与置信度**：加权 P25–P75 作区间；置信度 = `0.18 + 0.40 × 权重和 + 0.24 × 跨源一致性 + 0.18 × 时效`，单源时一致性项取 0.4。

| 层级 | 类型 | 权重 | 源数 |
|---|---|---|---|
| A | 政府法定统计 | 1.00 | 11 |
| B | 交易所官方定价 | 0.90 | 8 |
| C | 国际组织 | 0.85 | 6 |
| D | 持牌行业数据商 | 0.70 | 7 |
| E | 零售 / 渠道 / 批发平台 | 0.55 | 11 |
| F | 众包与二手 | 0.30 | 5 |

顶栏「权重」面板可实时调整，把 A 级拖到 0 就能看到价格和置信度一起变化。

## 下月预测

对官方序列近 60 个交易日做对数线性回归 `ln(p) = a + b·t`，取未来 30 天中点作为下月均价，区间用残差标准差 × 1.2816（80% 置信）。

- 走势图末端红色虚线为预测值，浅红区间带为置信区间
- 只能捕捉线性趋势，不预判政策、疫情与天气突变
- 定位为预算与议价的参考区间，不是承诺价

## API

| 路径 | 说明 |
|---|---|
| `GET /api/meta` | 分类树、城市表、数据源、覆盖度统计 |
| `GET /api/prices?product=&w=&month=` | 全城融合结果，`rows[].retail / .wholesale / .markupPct` |
| `GET /api/cell?product=&city=&w=` | 单城明细：两条口径的逐源报价、权重、偏离与剔除项 |
| `GET /api/rank?product=&basis=&order=&limit=&scope=` | 城市榜 |
| `GET /api/compare?product=&cities=&basis=` | 多城对比 |
| `GET /api/series?product=&city=&basis=` | 近 12 个月序列 |
| `GET /api/live/coverage` | 官方行情覆盖度 |
| `GET /api/live/series?product=` | 官方序列 + 下月预测 |
| `GET /api/search?q=` | 商品搜索 |

`w` 为 6 个逗号分隔的数字，依次对应 A~F 权重，例如 `w=1,0.9,0.85,0.7,0.55,0.3`；某位设为 0 即剔除该层级。

## 深链

```
#p=商品ID&s=cn|global&c=城市ID&cur=USD&t=rank|prov&b=retail|wholesale|markup
```

例：`#p=d0c0s0v0&s=cn&c=c0&b=wholesale`（籼米 · 中国 · 北京 · 批发口径）。

## 技术栈

React 18 · TypeScript 5 · Vite 5 · ECharts 5 · Express 4，样式为手写 CSS，无 UI 框架。

## 已知限制

- 每个子类只有 3 个代表规格，不是全量 SKU。
- 中国覆盖 203 个地级市，不是全部 333 个；海外 84 城分布不均。
- 金属矿产类无零售口径；部分小城市的批发口径只有 1~2 个源，置信度会明显偏低。
- 地图边界含台湾省、香港及澳门特别行政区、南海诸岛，不得替换为不合规底图。
- 前端打包约 1.2 MB（gzip 404 KB），主要是 ECharts 全量引入，可按需改为 `echarts/core`。
